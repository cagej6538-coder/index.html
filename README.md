## GitHub Pages deployment
1. Extract the ZIP.
2. Upload every file and folder to the root of the GitHub repository.
3. GitHub repository → Settings → Pages.
4. Select **Deploy from a branch** → `main` → `/root`.
5. Save and wait for the Pages URL.
